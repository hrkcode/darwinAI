# Darwin.AI

Chat com o Darwin, um professor de história virtual que responde perguntas sobre história usando a API da OpenAI.

## Como rodar localmente

1. Copie `.env.example` para `.env` e coloque sua chave da OpenAI em `API_KEY`.
2. Sirva a pasta com um servidor local (por exemplo, a extensão Live Server do VS Code).
3. Abra `index.html` no navegador.

> ⚠️ Nesta versão a chave é lida pelo navegador, então use apenas localmente. Não publique o site com o `.env` junto.

## Tecnologias

HTML, CSS e JavaScript puro.
